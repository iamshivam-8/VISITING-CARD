# 💳 Digital Visiting Card

A modern and responsive Digital Visiting Card built using **HTML, CSS, and JavaScript**.

This project showcases a professional digital profile card with a clean user interface, dark mode functionality, responsive layout, and clickable contact information.

---

## 📌 About the Project

The objective of this project was to practice frontend development fundamentals by creating an interactive digital business card.

It demonstrates responsive web design, modern UI principles, JavaScript DOM manipulation, and clean CSS styling.

---

## ✨ Features

- 🎨 Modern Glassmorphism UI
- 🌙 Dark / Light Mode Toggle
- 👤 Circular Profile Image
- 📧 Clickable Email
- 💻 GitHub Profile Link
- 💼 LinkedIn Profile Link
- 📱 Responsive Design
- ✨ Smooth Hover Effects
- 🎯 Clean and Minimal Layout

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Poppins)
